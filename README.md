# Student Grade Calculator — Python

A simple Python program that calculates student marks and determines the final grade.

## Features

- Takes student name as input
- Takes marks for multiple subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays PASS or FAIL result
